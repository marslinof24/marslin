# Workspace: compact course previews

2026-11-17. Local review only; no push.

## Direction

The owner prioritizes visual presentation. Workspace's lower half now contains
only Web scraping and Git, under Course exercises. Each preview is one native
link with an image, a name, and keywords. No process breakdowns, prose summaries,
extra calls to action, or hidden exercise panels remain.

Perfect Solution and the three website-development versions remain. Website
captures and captions sit alongside each other on desktop, stacking on mobile.
Portfolio's small practice index now points to the same two Workspace previews.
Unused screenshot assets remain in Git history/local assets; they are not loaded
by the revised pages.

The crawler uses Python, MariaDB, BS4, Requests, and SQL. MariaDB is retained
instead of substituting MySQL. The Git image is an original branch/merge
illustration, not a screenshot or a claim about a particular commit history.

## Visual reference and inference

- https://www.pentagram.com/ — the observed first screen gives project imagery
  most of the space, with short labels in a secondary role.
- https://www.lovefrom.com/ — a brief introduction with deliberately limited copy.

The design inference is to establish a strong image, then let a title and keywords
explain it. The owner's gray metal palette and Nunito remain. Neither reference
establishes a guaranteed five-second attention outcome; that needs user testing.

## Verification

Browser checks cover desktop and a 390 × 844 frame, links and keyboard focus,
website version switching, and the existing image viewer. No new page-transition
animation or routing architecture is introduced. New media reserves its aspect
ratio; hover does not change geometry and respects reduced motion.

Local resource validation and JavaScript syntax checks pass. These are simulated
browser checks, not physical-device usability or attention testing.
