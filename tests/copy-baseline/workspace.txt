What I wanted to try
I wanted a way to revisit the same situation instead of starting over each time. The demo lets me arrange both sides, play a scenario, pause it, and continue from a saved position.
What has been difficult
Setting up a scenario can become complicated when deck choices, unit placement, and playback controls all compete for attention. I've been refining how those controls are grouped and how the interface explains what can happen next.
Consistent feedback has also taken work: a selected card, a paused scene, and a rejected placement need to be easy to tell apart. Saving the current scene helps make repeated practice less dependent on rebuilding the setup.
Where it is now
The Windows demo supports scenario setup, interactive playback, and saving and loading a scene. Development and verification are ongoing; its behavior has not been verified as equivalent to the real game.
What comes next
My focus is to make the setup and practice flow easier to follow, check feedback across different situations, and compare observed behavior with the game before making stronger claims about accuracy.
